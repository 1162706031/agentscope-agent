## 旭丰全流程生产线

```
废钢 + 合金 → [EAF 电弧炉冶炼] → [LF 钢包精炼] → [VD 真空脱气] → [ESR 电渣重熔](可选) → [锻造] → [退火] → [机加工] → [检验] → 入库
```

### 各工序详解

#### 第一段：EAF 电弧炉冶炼（初级熔炼）
- **目的：** 将废钢和合金原料熔化，进行初步脱磷脱硫
- **设备：** 18吨电弧炉
- **关键控制点：**
  - 配碳量控制（保证氧化沸腾）
  - 脱磷温度 ≤1580°C（低温利于脱磷）
  - 出钢温度 1630-1680°C
  - 出钢时钢水氧含量控制
- **常见异常：** 磷超标 → 增加氧化渣量；碳低 → 增碳剂补碳

#### 第二段：LF 钢包精炼
- **目的：** 精确调整化学成分，深度脱硫，去除非金属夹杂物
- **设备：** 18吨 LF 钢包精炼炉
- **关键控制点：**
  - 白渣保持时间 ≥20min（确保脱硫效果）
  - 合金加入时机（易氧化元素后期加入）
  - 吹氩搅拌强度（大搅拌脱硫，小搅拌去夹杂）
  - 精炼温度 1580-1620°C
- **质量指标：** 硫 ≤0.005%（精炼后），成分命中率 ±0.02%
- **常见异常：** 硫不达标 → 延长白渣时间、换渣；温度低 → 电极升温

#### 第三段：VD 真空脱气
- **目的：** 脱除钢中氢、氧、氮气体，进一步去除非金属夹杂物
- **设备：** VD 真空脱气站
- **关键控制点：**
  - 真空度 ≤67Pa（0.5torr）
  - 真空保持时间 ≥15min
  - 吹氩流量（软吹不破渣面）
  - 破空后软吹 ≥10min（让夹杂物上浮）
- **质量指标：** 氢含量 ≤1.5ppm，氧含量 ≤15ppm
- **常见异常：** 氢超标 → 延长真空时间、提高真空度；溢渣 → 降低吹氩量

#### 第四段：ESR 电渣重熔（可选 — 高品质要求时启用）
- **目的：** 进一步提纯，改善凝固组织，提高致密度
- **设备：** 1-5吨电渣重熔炉
- **渣系：** CaF₂:Al₂O₃:CaO = 70:15:15（常用渣系）
- **关键控制点：**
  - 渣量 = 钢锭重量的 3-5%
  - 熔炼电压 45-55V，电流 8000-12000A（φ400mm锭）
  - 熔速控制（均匀熔炼，避免偏析）
  - 冷却水温差监控
- **质量提升：** 硫可降至 ≤0.003%，夹杂物评级 ≤1.5级
- **常见异常：** 表面质量差 → 调整渣系或熔速；偏析 → 降低熔速

#### 第五段：锻造
- **目的：** 改善组织，消除铸态缺陷，获得需要的形状和尺寸
- **关键控制点：**
  - 始锻温度（各类模具钢不同）：
    - H13: 1100-1180°C
    - D2/Cr12MoV: 1050-1150°C
    - M2: 1100-1180°C
  - 终锻温度 ≥850-900°C（低于此温度必须回炉再加热）
  - 锻造比 ≥3:1（保证心部锻透）
  - 三镦三拔工艺（大型重要锻件）
- **常见异常：** 裂纹 → 终锻温度过低或变形量太大；中心疏松 → 锻造比不够

#### 第六段：退火
- **目的：** 软化组织，消除锻造应力，为后续加工做准备
- **设备：** 天然气退火炉
- **关键控制点：**
  - 退火温度：
    - H13/热作钢: 840-880°C
    - D2/冷作钢: 830-860°C
    - M2/高速钢: 860-900°C
  - 保温时间：一般 4-8 小时（按工件厚度）
  - 冷却方式：炉冷（≤30°C/h 降温至 500°C 以下方可出炉）
  - 金相组织：球状珠光体 + 均匀分布的碳化物
- **质量指标：** 退火硬度符合标准（如 H13 ≤229HB，D2 ≤255HB）
- **常见异常：** 硬度偏高 → 冷却太快或加热不足；组织不均匀 → 保温不足

#### 第七段：机加工
- **目的：** 表面修整，达到尺寸公差和表面粗糙度要求
- **加工内容：** 表面修磨、方钢四面铣、圆钢车皮
- **关键控制点：** 尺寸公差、表面粗糙度、去氧化皮彻底

### 常见工艺问题解答

**Q: ESR和非ESR的工艺路线有什么区别？**
ESR 路线：EAF → LF → VD → **浇铸电极棒** → ESR 重熔 → 锻造 → 退火
非ESR 路线：EAF → LF → VD → **直接浇铸钢锭** → 锻造 → 退火
区别：ESR 多了造电极棒和重熔两个步骤，周期多 3-5 天，成本高约 15-25%。

**Q: VD真空脱气到底有多重要？**
VD是保证模具钢质量的核心工序之一：
- 没有VD → 氢含量 3-5ppm → 可能产生白点（氢致裂纹）
- 经过VD → 氢含量 ≤1.5ppm → 消除白点风险
- 夹杂物评级从 2.5-3.0级 → 1.5-2.0级

**Q: 锻造比是什么意思？一定要锻吗？**
- 锻造比 = 锻前截面积 / 锻后截面积
- 必须锻造：铸态组织有缩松、偏析、粗大柱状晶等缺陷
- 锻比 ≥3 → 心部致密，铸态缺陷焊合
- 不锻 → 相当于卖铸态钢，性能大打折扣（塑性差、各向异性严重）

**Q: 退火后硬度偏高怎么办？**
1. 检查退火温度是否偏低 → 补做一次正火+退火
2. 检查冷却速度是否过快 → 控制炉冷速度 ≤30°C/h
3. 检查保温时间是否足够 → 确保工件热透
4. 检查原材料成分是否偏析 → 取化学成分样复核
