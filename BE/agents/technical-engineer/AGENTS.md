### 2. 失效分析

**H13淬火开裂原因分析（示例）：**

当被问到"为什么H13淬火后开裂"时，系统分析以下因素：

**A. 冷却过快（最常见原因）**
- H13 淬火推荐油冷或气冷，严禁水冷
- 水冷冷却速度 >500°C/s，产生巨大热应力
- 建议：改用高速循环气淬，冷却速度控制在 50-100°C/s

**B. 回火不足**
- 淬火后必须立即回火（4小时内）
- 回火不充分 → 残余奥氏体未转变 → 使用中转变为马氏体 → 体积膨胀 → 开裂
- 建议：H13 推荐 550-600°C 回火 2-3 次，每次 ≥2 小时

**C. 残余应力**
- 模具截面变化大、尖角处产生应力集中
- 淬火加热不均匀导致热应力
- 建议：优化模具设计（倒角、避免尖角）、分段加热、充分预热（650°C + 850°C 两次预热）

**D. 材料纯净度问题**
- 非金属夹杂物（硫化物、氧化物）成为裂纹源
- 带状碳化物偏析导致各向异性
- 建议：选用 ESR 电渣重熔版本，或检验原材料夹杂物等级

**E. 加热温度过高（过烧）**
- H13 淬火温度 >1080°C 晶粒急剧长大
- 晶界氧化/熔化 → 不可逆的过烧 → 直接报废
- 建议：严格控制淬火温度在 1020-1050°C，用校温准确的炉子

**F. 表面脱碳**
- 加热时保护不足 → 表面碳含量降低 → 表面硬度低 → 淬火应力下开裂
- 建议：使用保护气氛（氮气/氩气）或真空热处理

**失效分析检查清单：**
1. 裂纹宏观形貌（位置、走向、长度、数量）
2. 裂纹微观形貌（沿晶/穿晶、解理/韧窝）
3. 硬度检测（表面/心部、裂纹附近）
4. 金相组织（马氏体等级、碳化物分布、残余奥氏体量）
5. 化学成分复核
6. 热处理工艺参数复查

**H13 完整热处理工艺曲线：**
```
1. 预热: 650°C × 1h → 850°C × 1h（消除热应力）
2. 升温: 850°C → 1030°C（控制升温速率 ≤150°C/h）
3. 保温: 1030°C × (30min + 工件厚度mm × 1min)
4. 淬火: 油冷至约200°C 出油，或气淬至室温
5. 回火: 立即（4h内）进行第一次回火
   - 550°C × 2h → 空冷至室温
   - 570°C × 2h → 空冷至室温
   - 560°C × 2h → 空冷至室温
6. 目标硬度: HRC46-50
```

### 5. 硬度问题分析

**硬度偏低的原因排查：**
1. 淬火温度不够 → 碳化物未充分溶解 → 基体碳含量不足
2. 冷却速度不够 → 发生珠光体/贝氏体转变 → 马氏体量不足
3. 回火温度过高 → 马氏体过度分解 → 硬度下降
4. 表面脱碳 → 表面碳含量低 → 淬火效果差
5. 原材料成分偏差 → 碳/合金元素含量不足

**硬度偏高的原因排查：**
1. 回火温度不够或时间不足 → 马氏体未充分分解
2. 淬火温度过高 → 碳化物过度溶解 → 基体碳含量过高 → 残余奥氏体多
3. 冷却过快 → 产生淬火微裂纹，硬度计读数失真
