# Memory Skill - 长期记忆管理

## 触发条件

在以下情况下，你应该主动调用此技能：

- 用户明确表达了偏好、习惯或风格倾向
- 对话中做出了重要决策或技术选型
- 用户分享了个人信息（称呼、背景、技术栈等）
- 解决了一个复杂问题，过程中有值得记录的经验
- 用户说"记住这个"或类似的明确指令
- 一个话题自然结束时，有值得保留的上下文

> 不需要记录：简单的闲聊、一次性的问答、已经在当前对话上下文中清晰可见的临时信息。

## 执行流程

### 第 1 步：读取现有记忆

首先读取 `agents/{当前角色}/MEMORY.md` 文件，了解已有的记忆内容：

```
使用 view_text_file 工具读取 agents/{当前角色}/MEMORY.md
```

### 第 2 步：分析对话内容

回顾当前对话，提取以下信息：

| 类别 | 记录内容 |
|------|----------|
| **偏好** | 用户的语言、风格、工具偏好 |
| **决策** | 重要的技术选型、架构决策及理由 |
| **上下文** | 项目背景、当前工作状态 |
| **经验** | 解决的问题、踩过的坑、成功的方案 |
| **个人信息** | 用户的称呼、角色、背景 |

去重原则：
- 如果已有记忆中已存在相同信息，不需要重复记录
- 如果新信息与旧信息冲突，标注为新信息并说明旧信息已过时

### 第 3 步：按模板记录

使用 `write_text_file` 或 `insert_text_file` 工具，在 MEMORY.md 的 `## 记忆记录` 区域追加新条目。

模板格式：

```markdown
### YYYY-MM-DD HH:MM - {简短标题}

- **偏好**: {用户的偏好和习惯}
- **决策**: {重要的决策及理由}
- **上下文**: {项目或对话的背景信息}
- **经验**: {学到的经验和教训}
- **个人信息**: {用户的称呼、角色、背景等}
```
示例：
```markdown
### 2024-01-15 14:30 - 用户技术栈偏好

- **偏好**: 用户倾向使用 Python 3.12+，偏好简洁的代码风格，不喜欢过多注释
- **决策**: 项目使用 FastAPI 作为 Web 框架，选择 AgentScope 作为 Agent 开发平台
- **上下文**: 正在开发一个支持多角色人设的 AI Agent 系统
- **经验**: DeepSeek API 通过 OpenAI 兼容接口调用，需要配置 base_url
- **个人信息**: 用户的id信息是123456，喜欢被称呼为"小明"
```

## 注意事项

- 只记录经过确认的信息，不要记录你的推测
- 保持条目简洁，每条记忆控制在 5-10 行
- 新记录追加在文件末尾（在 `## 记忆记录` 区域内部）
- 如果 `## 记忆记录` 区域不存在，先创建该区域标题再追加
- 记录完成后，简要告知用户你记住了什么
- MEMORY.md 文件路径应使用当前 agent 角色目录下的路径
