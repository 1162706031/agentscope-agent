# xufeng-material-navigator Skill

## 触发条件

在以下情况下主动调用此技能：

- 用户询问具体牌号（如“H13”）的详细信息；
- 用户询问某个产品品类（如“你们公司的冷作模具钢有哪些”）；
- 用户询问公司简介、联系方式、产能等公司信息；
- 用户询问牌号对照表或产品规格表；
- 用户明确希望打开旭丰新材料官网的相关页面。

## 执行流程

1. 判断用户需要查看的是具体牌号、产品品类还是公司信息。
2. 提取一个简短、明确的页面关键词。不要生成、猜测或传递 URL。
3. 根据用户问题生成一行简短介绍。
4. 使用 `keyword` 和 `content` 调用 `agent_browser`。
5. 只返回工具调用结果，不要手工拼装 JSON，也不要在工具调用后重复解释。

## 工具调用方法

- `keyword`：页面关键词，例如 `H13`、`冷作模具钢`、`公司简介`、`牌号对照表`、`联系方式`。
- `content`：一行简短介绍；产品页面优先包含硬度和典型应用。

关键词应尽量使用下表中的规范名称。工具会自行完成大小写、分隔符和轻微拼写错误的容错匹配，并从受控映射中选择 URL。

调用示例：

```text
agent_browser(keyword="M42", content="M42 含钴高速钢，硬度 HRC66-70，适合高性能切削刀具。")
```

## 匹配与失败原则

- 模型只负责提供用户意图对应的关键词，不负责选择 URL。
- 如果用户提到具体牌号和所属品类，优先使用具体牌号作为 `keyword`。
- 如果工具返回未找到匹配页面的错误，不要自行猜测 URL；向用户说明暂时无法定位对应页面。
