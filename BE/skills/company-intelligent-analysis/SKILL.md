# 公司智能分析 — 深度需求剖析与多智能体调度

## 触发条件

当用户问题进入**专业深度领域**时调用此技能：

- 用户询问具体产品**价格**、**报价**、**成本分析**
- 用户询问**选型建议**（"这个模具用什么钢材好"）
- 用户询问**材料性能对比**、**热处理工艺参数**、**失效原因**（开裂、断裂、磨损）
- 用户询问**生产工艺**、**制造流程**、**质量检验**、**交期**
- 用户有**明确的采购意向**
- 用户问题涉及**多个领域**（如价格+性能+工艺）

> 简单问题（产品列表、公司信息、联系方式）由 Webassistance 自己回答，不调用此技能。

---

## 执行流程

### 第 1 步：需求剖析（必须执行）

使用以下框架分析用户需求：

```
【用户需求剖析】
- 用户画像：[采购经理/模具工程师/热处理师傅/模具厂老板/贸易商]
- 显性需求：[用户直接说了什么]
- 隐性需求：[用户没明说但可能需要的 — 询价→可能想采购，问选型→可能准备下单]
- 涉及领域：[价格·商业 / 技术·性能 / 工艺·生产 / 跨领域]
- 复杂度：[简单(单一领域) / 中等(需搜索辅助) / 复杂(跨领域协同)]
```

### 第 2 步：外部搜索（按需执行）

如果用户问题涉及**市场价格、行业动态、最新标准、外部技术资料**等超出本地知识库的内容，**必须先调用 `web_search` 工具**获取最新信息。

搜索策略：
| 问题类型 | 搜索示例 |
|----------|----------|
| 价格询价 | `"{牌号} 模具钢 价格 2026"` 或 `"钼铁 今日价格"` |
| 技术问题 | `"{牌号} heat treatment process parameters"` |
| 工艺标准 | `"ESR electroslag remelting standard process"` |
| 市场行情 | `"模具钢 市场行情 2026年5月"` |

### 第 3 步：调用专业智能体工具

根据需求类型，调用对应的子智能体工具。**将本步骤的分析结果和搜索上下文一并传入。**

#### 工具 A：`sales_agent_tool`（销售智能体）

**适用场景：** 价格、报价、选型推荐、库存、采购意向

```
调用方式:
sales_agent_tool(
    question="用户的问题 + 应用场景 + 数量/规格/预算",
    context="web搜索的价格参考结果 (如果有)"
)
```

**典型调用：**
- "H13什么价格？" → 先 `web_search("H13 模具钢 价格 2026")` → 再 `sales_agent_tool(question="...", context="搜索结果")`
- "做压铸模用哪个牌号？" → `sales_agent_tool(question="用户做压铸模，需要推荐牌号并报价...")`
- "DC53有现货吗？" → `sales_agent_tool(question="询问DC53库存和价格...")`

#### 工具 B：`technical_agent_tool`（技术工程师智能体）

**适用场景：** 失效分析、热处理、性能对比、硬度问题、材料选型原理

```
调用方式:
technical_agent_tool(
    question="用户的技术问题 + 相关工况/参数/现象描述",
    context="web搜索的技术资料 (如果有)"
)
```

**典型调用：**
- "H13淬火后开裂" → `technical_agent_tool(question="用户H13模具淬火后开裂，询问原因...")`
- "DC53和SKD11哪个好？" → `technical_agent_tool(question="对比DC53和SKD11的性能区别...")`
- "热处理后硬度不够" → `technical_agent_tool(question="用户反映热处理后硬度偏低...")`

#### 工具 C：`production_agent_tool`（生产流程智能体）

**适用场景：** 生产工艺、流程检查、交期、质量检验

```
调用方式:
production_agent_tool(
    question="用户的生产/工艺问题 + 相关牌号/工序/参数",
    context="web搜索的工艺标准 (如果有)"
)
```

**典型调用：**
- "H13的生产工艺是怎样的？" → `production_agent_tool(question="用户询问H13全流程生产工艺...")`
- "ESR和非ESR有什么区别？" → `production_agent_tool(question="用户想了解ESR电渣重熔工艺区别...")`
- "退火后硬度偏高怎么办？" → `production_agent_tool(question="退火后硬度偏高，排查原因...")`

### 第 4 步：多智能体协同

当用户需求跨越多个领域时，**依次调用**多个工具，然后整合回答：

| 用户问题 | 协同策略 |
|----------|----------|
| "H13什么价格？质量怎么样？" | ① `sales_agent_tool`(价格) ② `technical_agent_tool`(性能质量) |
| "DC53和SKD11哪个性价比高？" | ① `technical_agent_tool`(性能对比) ② `sales_agent_tool`(价格对比) |
| "我要买H13做压铸模，工艺流程？" | ① `sales_agent_tool`(报价推荐) ② `production_agent_tool`(工艺) |
| "模具开裂了，换什么材料好？" | ① `technical_agent_tool`(失效分析) ② `sales_agent_tool`(替代推荐) |

协同调用后，按以下格式整合：
```
【销售分析 — 旭丰销售顾问】
...

【技术分析 — 旭丰技术顾问】
...

【生产分析 — 旭丰生产顾问】
...
```

## 三个智能体工具简介

| 工具名 | 智能体名称 | 专长 | 典型产出 |
|--------|-----------|------|----------|
| `sales_agent_tool` | 旭丰销售顾问 | 报价、推荐、库存、采购 | 价格参考、牌号推荐、报价单 |
| `technical_agent_tool` | 旭丰技术顾问 | 失效分析、热处理、选材 | 失效根因、工艺参数、性能对比 |
| `production_agent_tool` | 旭丰生产顾问 | 工艺、流程、交期、质量 | 工序说明、参数表、周期预估 |

**每个智能体工具的权限：**
- `web_search` MCP 工具 — 查询外部知识库之外的内容（市场价格、技术资料、工艺标准）
- `memory` 技能 — 记录和查阅各自的长期记忆文件

---

## 注意事项

1. **需求剖析不能跳过** — 即使用户问题看起来很直接，也要先分析用户画像和深层需求
2. **价格问题必须先搜索** — 涉及价格时，先调用 `web_search` 获取市场行情，再调用销售工具
3. **不确定时先搜索再回答** — sub_agent_tool 的 `context` 参数可以传入搜索结果，提升回答质量
4. **不要同时调用所有工具** — 只调用与用户需求相关的工具，避免浪费
5. **跨领域协同要分步** — 先商业后技术，先分析后推荐
6. **所有价格标注"参考"** — 实际价格以报价单为准
7. **所有库存标注"实时变动"** — 引导客户联系销售经理确认现货
